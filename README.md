# Tarclick

Небольшой веб-сайт с изображениями и интерактивностью на JavaScript.

## Файлы проекта

- `index.html` — разметка страницы.
- `style.css` — оформление и стили.
- `script.js` — интерактивное поведение.
- `factory.jpg.png`, `forest.jpg.png`, `mall.jpg.png` — изображения проекта.

## Запуск

Откройте `index.html` в браузере.

Для удобной разработки можно запустить локальный сервер, например с помощью расширения **Live Server** в Visual Studio Code.

## Технологии

- HTML
- CSS
- JavaScript
